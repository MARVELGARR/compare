# Compare

A modern, high-performance web application built with **Next.js 16** and **React 19**, designed to compare data sets with a focus on speed and developer experience.

## 🎯 Aim
The goal of this project is to provide a seamless and intuitive interface for comparing complex data objects, leveraging modern web technologies to ensure a responsive and reliable user experience.

## 🚀 Objectives
- **Efficiency**: Minimize load times and optimize data fetching using React Query.
- **Scalability**: Build a modular architecture using the Next.js App Router for easy feature expansion.
- **Durability**: Implement client-side persistence for query results to reduce redundant API calls.
- **Styling**: Utilize Tailwind CSS 4 for a sleek, modern, and responsive UI.

## 🛠️ Tools & Dependencies
This project leverages a state-of-the-art tech stack:

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **State Management**: [@tanstack/react-query](https://tanstack.com/query/latest) (v5)
- **Persistence**: `@tanstack/query-async-storage-persister` & `@tanstack/react-query-persist-client`
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Language**: [TypeScript 5](https://www.typescriptlang.org/)

## 🏗️ Architecture
The project follows a standard Next.js App Router structure, ensuring a clean separation of concerns:

- `src/app/`: Contains the application routes, layouts, and page-specific components.
- `src/providers/`: Houses context providers, including the `ReactQueryProvider` for global state management.
- `src/utils/`: General-purpose utilities and API client abstractions.
- `src/apis/`: (In Progress) Dedicated layer for external API interactions (e.g., Spotify integration).

## 🔄 Data Flow
The application utilizes an asynchronous data flow managed by **React Query**:

1. **Request**: UI components trigger data fetching through hooks.
2. **Fetching**: The `apiClient` or specific API modules handle the network requests.
3. **Caching**: React Query manages the cache, lifecycle, and re-fetching logic.
4. **Persistence**: The query state is persisted to `localStorage` using an async storage persister, allowing for offline access and faster subsequent loads.
5. **State Sync**: React Query automatically synchronizes the server state with the UI.
